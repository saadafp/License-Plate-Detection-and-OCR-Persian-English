## Datasets and Acknowledgements

### Plate Detection

The plate detection model was trained on two datasets:

1. [License Plate Dataset](https://www.kaggle.com/datasets/ronakgohil/license-plate-dataset) by Ronak Gohil (Kaggle)
2. [Iranian Car Number Plate](https://www.kaggle.com/datasets/skhalili/iraniancarnumberplate) by S. Khalili (Kaggle)

### Persian Character Recognition

The Persian OCR model is based on and inspired by [iranian-license-plate-recognition](https://github.com/amirmgh1375/iranian-license-plate-recognition) by amirmgh1375 (GitHub).
